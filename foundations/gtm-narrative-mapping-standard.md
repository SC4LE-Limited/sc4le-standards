# SC4LE GTM → Narrative Mapping Standard  
© 2026 SC4LE Limited — Foundations Layer

This standard defines how SC4LE converts ICP behaviour, pains, and strategic pressures into **founder-friendly, consequence-led narratives**.

It operationalises the SC4LE Narrative Architecture for GTM, ensuring consistent messaging across:

- offerings  
- diagnostics  
- advisory work  
- website content  
- AI Maturity Agent onboarding  

This file is part of the SC4LE Foundations Layer.

---

## 1. Purpose  
The GTM → Narrative Mapping Standard defines the **pain → consequence → outcome → SC4LE principle** chain for each ICP.

It ensures SC4LE can:

- explain problems clearly  
- articulate consequences credibly  
- position outcomes meaningfully  
- map ICP behaviour to SC4LE principles  
- generate founder-friendly messaging  
- maintain narrative coherence across all GTM channels  

This is the Golden Source for SC4LE storytelling logic.

# 4.1 Scrappy Sam (Pre‑Seed) — Narrative Map

### Pain  
(See GTM Standards for full ICP pain list)  
- Urgency everywhere  
- No clear priorities  
- Inconsistent decisions  
- Chaos slows execution  

### Consequence  
(See GTM Standards for consequence language)  
- Slow progress despite high effort  
- Burnout risk  
- Missed opportunities  
- Constant rework  

### Outcome  
(See GTM Standards for outcome language)  
- Clarity on what matters  
- Faster decisions  
- Reduced chaos  
- Predictable weekly progress  

### SC4LE Principle Mapping  
- **Clarity First** → weekly clarity cadence  
- **Flow Over Activity** → eliminate friction  
- **Decision Pathways** → reduce decision latency  

### Narrative Example  
“Everything feels urgent, which creates chaos and slows you down. The consequence is that you’re working hard but not moving fast. SC4LE gives you clarity on what matters each week so you can make faster decisions and reduce chaos.”
